# NorthPeak Roofing

A modern roofing company website with a React frontend and Express backend.

## Tech Stack

* React
* Vite
* JavaScript
* Node.js
* Express.js
* MongoDB

## Project Structure

```text
NorthPeak-Roofing/
├── src/        # Frontend
├── server/     # Backend
└── README.md   # Project documentation
```

## Running the Project

### Frontend

```bash
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```

### Backend

```bash
npm run server
```

Backend runs on:

```text
http://localhost:5000
```
